בתוך שיחה עם Claude Code, יש פקודות מיוחדות:

/help רשימת כל הפקודות
/clear נקה היסטוריה — שיחה חדשה
/compact דחס היסטוריה לחסכון ב-tokens
/cost כמה tokens השתמשת
/model החלף מודל (Opus/Sonnet/Haiku)
/review קוד ריוויו על השינויים הנוכחיים
טיפ: /compact לשיחות ארוכות
אחרי ~20 הודעות, כתוב /compact — הוא יסכם ויחסוך tokens משמעותית.

טיפים שיחסכו לך זמן
מה שמבדיל בינוני ממומחה
טיפ 1: תן הקשר בהתחלה
"אני בונה React + TypeScript + Firebase. עובד על מודול התחברות. צריך login עם Google."

ככל שתתן יותר הקשר בהתחלה, התוצאות יהיו טובות יותר.

טיפ 2: צור CLAUDE.md בפרויקט

Claude Code קורא את הקובץ הזה אוטומטית בכל שיחה:

# הוראות לפרויקט - שפה: TypeScript - בדיקות: Jest - כל פונקציה חייבת JSDoc

חוסך הסברים חוזרים בכל שיחה.

טיפ 3: בדוק שינויים עם git diff
git diff # ראה מה השתנה git add . git commit -m "feat: תיאור השינוי"
טיפ 4: צעד אחד בכל פעם
אל תבקש 5 דברים בבת אחת. שאלה אחת → בדוק → שאלה הבאה. זה הרבה יותר יעיל.
טיפ 5: בקש הסברים
"עשית את השינוי — הסבר לי למה בחרת בגישה הזו"

זה הדרך הכי מהירה ללמוד.
